|------|------|---------|
| ✅ **Revolve 运行时崩** | `Tool_Revolve()` | 去掉 RegionBoundaryRule + Axis 对象，改用 SetSketch + SetAxis + Limits + Commit 模式 |

```csharp

```

**Translate 修复细节：**

```csharp
// ❌ 旧代码：方向未归一化
mb.TransformMotion.DistanceValue.RightHandSide = Math.Sqrt(dx*dx+dy*dy+dz*dz).ToString();
mb.TransformMotion.DistanceVector = wp.Directions.CreateDirection(..., new Vector3d(dx,dy,dz), ...);

// ✅ 新代码：归一化方向向量，距离和方向分离

if (dist < 0.001) return;  // 零距离不执行
mb.TransformMotion.DistanceValue.RightHandSide = dist.ToString();
mb.TransformMotion.DistanceVector = wp.Directions.CreateDirection(..., new Vector3d(nx,ny,nz), ...);
// 方向向量 (nx,ny,nz) = (dx/dist, dy/dist, dz/dist)，是单位向量
```

**Rotate 修复细节：**

```csharp
// ❌ 旧代码：Axis 对象传给 Direction 属性

// ✅ 新代码：用 CreateDirection
```

### 2.2 各问题详解

#### 问题 1：Revolve — memory access violation

**当前代码**（backend/journal/nx_modeler.cs）：

```csharp
// ❌ 当前实现：使用 RegionBoundaryRule + Section + Axis + CommitFeature
Section sec = wp.Sections.CreateSection(0.0095, 0.01, 0.5);
sec.SetAllowedEntityTypes(Section.AllowTypes.OnlyCurves);
RegionBoundaryRule br = wp.ScRuleFactory.CreateRuleRegionBoundary(
    curSketch, curCurves.ToArray(), seed, 0.01, ro);
sec.AddToSection(new SelectionIntentRule[]{br}, null, null, null, seed, Section.Mode.Create, false);
Axis axis = wp.Axes.CreateAxis(new Point3d(0,0,0), new Vector3d(0,0,1), ...);
RevolveBuilder rb = wp.Features.CreateRevolveBuilder(null);
rb.Section = sec;  rb.Axis = axis;
// ...
rb.CommitFeature();  // ← 这里 memory access violation
```

**根因**：`RegionBoundaryRule` + `Section.AddToSection` 的组合在 NX2412 中导致内核访问违规。这种方式过于复杂，用了不稳定的 API 路径。

**参考（来自 NX_MCP，已验证可工作）**：

```python
# ✅ NX_MCP 的正确实现
builder = work_part.Features.CreateRevolveBuilder(None)
builder.SetAngle(expr, angle, Unit.Degree)  # 直接设角度
builder.SetAxis(axis_vec)                    # 直接设轴
builder.SetSketch(sketch)                    # 直接设草图
builder.Commit()                             # 正常 Commit
```

**修复方向**：C# 中改用同样的 `SetAngle + SetAxis + SetSketch + Commit` 简单路径。

---

#### 问题 2：Translate — "motion specified is invalid"

**根因**：`MoveObjectBuilder` 的参数配置有误，可能使用了错误的移动类型或方向向量。

**修复方向**：录一次正确的 NX Journal，确认 `MoveObjectBuilder.DistanceAngle` 的正确参数。

---

#### 问题 3：Rotate — "feature has zero parameters"

**根因**：`MoveObjectBuilder.Angle` 旋转参数有误，可能角度单位或旋转轴向量配置错误。

**修复方向**：与 Translate 类似，需要 Journal 验证正确的参数格式。

## 三、修复方案

### Phase 1：修复 P0 运行时崩溃 ✅ 已完成

| 问题 | 状态 | 关键改动 |
|------|------|---------|
| **Revolve** | ✅ 已修复 | 去掉 RegionBoundaryRule+Section+Axis+CommitFeature，换 SetSketch+SetAxis+Limits+Commit |
| **Translate** | ✅ 已修复 | 归一化方向向量，零距离检查 |
| **Rotate** | ✅ 已修复 | Axis → Direction（CreateDirection），增加 CenterPoint |

**核心经验：** NXOpen C# 中的几个崩/错都源于同一个问题——`Axis` 对象（`wp.Axes.CreateAxis`）传给期望 `Direction` 类型的属性。全部换成 `wp.Directions.CreateDirection` 或直接用 `Vector3d` 解决。
