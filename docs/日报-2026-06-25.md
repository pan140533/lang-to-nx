### 3. 修复 3 个 P0 运行时崩溃

| Bug | 根因 | 修复 |
|-----|------|------|
| **Revolve → memory access violation** | `RegionBoundaryRule` + `Axis` 对象组合导致 NX 内核崩 | 换成 `SetSketch()` + `SetAxis(Vector3d)` + `Commit()` |
| **Translate → "motion specified is invalid"** | 方向向量未归一化 | 距离/方向分离，向量归一化 |
| **Rotate → "feature has zero parameters"** | `Axis` 对象传给 `Direction` 属性 + 缺旋转中心 | 换成 `CreateDirection` + `CenterPoint` |
